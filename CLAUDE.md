# NovelForge contributor instructions

Follow [AGENTS.md](AGENTS.md). The authoritative planning artifacts are:

- `docs/audit/01-reference-feature-matrix.md`
- `docs/architecture/`
- `docs/phases/`

Before implementation, read the active Phase specification and related architecture documents. Keep production workflows real, persisted, resumable, observable, and tested. Do not substitute static UI, mocked API responses, alerts, or `setTimeout` simulations for a feature.
