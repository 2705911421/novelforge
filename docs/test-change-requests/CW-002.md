# CW-002: migration version assertion is behind the working schema

## Affected test

`tests/test_phase1_persistence.py::test_migration_engine_records_versions_and_rejects_checksum_tampering`

## Finding

The test asserts that the maximum `schema_migrations.version` is `15`, while
the current working tree already contains migrations 16 and 17 before the
Agent extension scope migration added for the current feature. The correct
invariant is that the database reaches the current migration registry and
rejects checksum tampering; a hard-coded historical maximum makes the test
fail on every current fresh database.

## Requested test change

Assert against the current migration registry (or update the expected version
to the release's intended migration number) while retaining the checksum
tampering assertion. This request does not authorize weakening or removing the
tamper-detection check.
