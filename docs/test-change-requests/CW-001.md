# CW-001 Acceptance Test Change Request

## Problem

`spec/features/continuous-writing.yaml` maps the continuous-writing contract to
`tests/test_l27_l28_l29.py`. That file contains rate limiter, dialogue cache and
character theme tests; its `test_autosave_endpoint_accepts_chapter_save` body is
only `pass`. Passing the mapped command therefore does not exercise the stated
continuous-writing requirements: durable parent/child state, checkpoints,
failure accounting, pause/resume/cancel or recovery.

## Proposed protected change

Replace the acceptance mapping with a dedicated suite covering:

- a 5-chapter happy path with one durable child and StoryCommit per chapter;
- quality-gate failure that leaves the parent in `needs_author_decision`;
- pause/resume from a persisted checkpoint;
- cancellation at a provider boundary;
- lease-expiry/restart replay with idempotent completed children;
- count validation for the backend 5-200 contract.

The existing protected tests and feature contract must remain unchanged until an
authorized maintainer approves this request. The independent regression suite
in `tests/adversarial/test_p0_workflow_integrity.py` provides interim evidence,
but does not replace the protected contract.
