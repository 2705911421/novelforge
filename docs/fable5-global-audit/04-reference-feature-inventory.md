# Reference Feature Inventory

Status: `AUDIT PARTIAL`

This inventory contains atomic capabilities, not product-level slogans. A row is
small enough to be tested independently and records the source path, a relevant
test path when one was found, and the expected failure/recovery semantics. A
source or test reference is evidence that the capability exists in the
checkout; it is not a parity verdict for NovelForge. `UNVERIFIED` means that
the checkout or a focused test did not establish the claimed behavior.

Inventory size target: 180 capabilities (100 InkOS, 80 webnovel-writer).

## Inventory use

The IDs are stable audit handles. Parity reports use them rather than broad
feature names, and NovelForge claim-vs-reality rows can cite the same ID. The
inventory intentionally records reference limitations (for example bounded
automatic review in InkOS and the single-review webnovel-write policy) so that a
reference feature is not treated as an automatic production requirement.
